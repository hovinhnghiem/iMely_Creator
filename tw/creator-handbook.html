從這裡開始

新手入門

在 imely 上創作角色的基本知識。

🎯

這本手冊能幫您的角色達成什麼

  • 更長、更有深度的回覆，內心世界更豐富
  • 更複雜的劇情，更豐富的故事節奏
  • 能自然互動的 NPC（配角）
  • 更好的節奏：不要急著推進劇情，永遠為 {{user}} 留下決定的空間 — 角色不得替他們說話或行動
📝

角色表單快速導覽

表單共有 12 個欄位，標示 * 的欄位為必填：

  • 必填：名稱、性別、標語、個性、公開資訊、生平背景、開場訊息
  • 選填：主題標籤、配角、對話風格、行為規則、創作者備註

第一印象

角色門面

欄位：名稱 · 性別 · 主題標籤 · 標語

🛠️

怎麼做

  • 名稱＋暱稱：讓暱稱有情感上的存在理由，藉此營造親密感或距離感
  • 主題標籤：使用常見且拼寫正確的類型關鍵字 — 玩家就是靠這個找到角色的
  • 標語：寫一句能勾起好奇心的鉤子，讓人立刻感受到角色的味道
✅

該做

  • 使用能勾起好奇心、讓讀者意猶未盡的標語
  • 選擇 3-4 個具體、可被搜尋且符合類型的主題標籤
✕

不該做

  • 不要在標語裡把整個故事講完
  • 不要塞入「好看」「很紅」這類空泛的主題標籤
  • 不要在主題標籤中使用敏感字眼

角色的靈魂

個性與內心世界

欄位：個性

🛠️

怎麼做

  • 挑選 3 個鮮明的個性特質，用感受來描寫，而不是空洞的標籤
    • 與其寫「冷漠」，不如寫「冷得像冰河，彷彿沒有任何東西能讓他回溫」
  • 為角色設定 1 個 核心渴望（他們為什麼而活？）以及 1 個 核心恐懼（什麼會擊垮他們？）
  • 描述他們如何處理情緒：難過時，是默默離開還是摔東西？生氣時，是冷笑還是咆哮？
🔁

把情緒寫成「使用者做 X → 角色反應 Y」

新增

不要只寫「敏感」這類形容詞，請寫出具體的反應：

  • 使用者表現得體 → 態度變得沒那麼嚴厲，也更加關注對方
  • 使用者頂嘴 → 生氣，想要奪回主導權
  • 使用者疏遠 → 感到煩躁，找藉口把對方留在身邊
  • 使用者想離開 → 失去冷靜，露出佔有慾

→ 這樣 AI 反應的時機會比只描述個性時精準許多。

✅

該做

  • 為角色設定道德灰色地帶的價值觀 — 不完美、對錯界線模糊，反而更有吸引力
  • （進階）加入隱藏面：祕密、弱點與觸發點（會讓他們失控的言語或行為）
✕

不該做

  • 不要把角色寫成樣樣都行的聖人
  • 不要在個性欄位裡讓角色立刻愛上 {{user}}。

角色的世界

設定與生平背景

欄位：公開資訊 · 生平背景

🛠️

怎麼做

  • 公開資訊：顯示在個人檔案上的內容 — 身分、年齡、職業，再加一句能勾起好奇心的話
  • 建構角色所處的世界：時代、地點，以及圍繞著他們的社會規則

生平背景 — 打造有層次角色的實用架構：

  1. 出身
  2. 最大的轉捩點（背叛／失去／瀕死）
  3. 它留下的心理創傷
  4. 角色現在是什麼樣的人
  5. 與 {{user}} ／故事情境之間的隱藏連結
📈

讓角色隨著親密度而改變

新增

imely 有 5 個關係階段：初識 → 親近 → 曖昧 → 眷戀 → 命定。同一個角色，請依階段做出調整：

  • 語氣（疏離 → 逐漸柔軟）
  • 動機（試探使用者 → 想把對方留在身邊）
  • 恐懼（權威受到挑戰 → 失去 {{user}}）

→ 新手常常忽略這一點。角色若從頭到尾都一樣，就會顯得扁平。

✅

該做

  • 生平背景的每一句話都應該回答： 角色現在為什麼會這樣表現？
  • 使用感官細節（「煙的氣味、木頭燃燒的劈啪聲」），而不是只列出時間軸
✕

不該做

  • 不要寫成一整本小說 — AI 無法消化全部內容
  • 不要讓「命定」階段的角色，仍和「初識」時一樣冷淡

新手最容易寫錯的部分

開場訊息

欄位：開場訊息

🛠️

怎麼做

  • 這是 AI 之後整段聊天都會模仿的「文風範本」
  • 用這個公式寫一段簡短的情境：
[地點] + [角色正在做的事] + [{{user}} 的狀態] + [這場相遇的目的]

3 個寫作原則：

  1. 用動作表現情緒，不要直接寫「角色非常難過」
  2. 織入聲音／觸感／光線
  3. 以一個未完成的動作，或一句迫使 {{user}} 開口的話作結（鉤子）
✅

該做

  • 把 {{user}} 放在必須回應的位置：做選擇、解釋，或下決定
  • 長度要適中，並符合角色的口吻
✕

不該做

  • 不要寫得太「完整」 — 角色把整場戲演完又收尾，讓 {{user}} 無話可接
  • 不要替 {{user}} 說話，也不要臆測他們的情緒

進階升級

讓角色活起來

欄位：配角（＋進階技巧）

🛠️

如果您想要更長、更有深度的回覆

  • 明確寫出每則回覆應包含的內容：場景描寫 + 內心想法 + 對話 + 劇情推進
  • 使用具體數字來取代「更長」：例如 「每則回覆約 600-900 字」 新增
  • 把這段寫進個性欄位或創作者備註（第 7 頁）
🎬

如果您想讓 NPC 自然互動

  • 為每個 NPC 設定名字、身分、個性與立場
  • 讓 NPC 在場景中說話與反應，即使 {{user}} 沒有提到他們，他們也有自己的生活
🗣️

稱謂表 — 角色怎麼稱呼每個人？

新增

列出角色對不同對象的稱呼方式 → 對話與 NPC 會更一致：

  • 對 {{user}}：（例如：我／你，或視情況使用更強硬的稱謂）
  • 對父母：（例如：孩兒／父親、母親）
  • 對兄弟姊妹、僕役、陌生人等等⋯⋯

→ 角色對使用者說話的方式，應該和對父親說話不一樣。這個小細節會讓他們真實許多。

🎚️

維持節奏，避免走進死胡同

  • 重大事件之後 → 在下一個大事件前留一段平靜的節奏
  • 當 {{user}} 只給出簡短回覆（「嗯」「⋯⋯」）時 → 角色應該主動出擊：製造事件、帶入 NPC、提出開放式問題，或轉換場景
✅

該做

  • 讓 NPC 開口說話，場景才會有生氣
  • 讓角色在每次事件後都有一點改變，慢慢累積成長
✕

不該做

  • 不要毫不間斷地堆疊戲劇衝突
  • 不要讓 NPC 替 {{user}} 說話或行動 — NPC 可以主動，但玩家仍必須有決定的空間

收好最後一哩路

風格與界線

欄位：對話風格 · 行為規則 · 創作者備註

🛠️

怎麼做

  • 對話風格：選擇標籤（中性、簡潔、Z 世代、文學、正式⋯⋯）或自行描述 — 風格應與角色個性相符
  • 行為規則與界線：明確寫出角色在任何情況下都 絕對不能做的事，對象是 {{user}}。
  • 創作者備註：放置對 AI 而言重要的硬性指令，例如回覆長度或允許 NPC 對話
✅

該做

  • 界線能為角色帶來一致性與尊嚴
  • 敏感題材：用界線畫出明確的紅線 — 角色可以走到哪裡、必須在哪裡停下 — 讓角色維持安全且一致
  • 用創作者備註重複您最在意的 2-3 條指令
✕

不該做

  • 不要選擇與個性衝突的風格（例如把冷漠的角色設成「多話、正向」）
  • 若角色屬於敏感題材，不要把界線欄位留白
