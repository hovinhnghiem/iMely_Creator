活動規則與參加條件

01
活動規則
  • 未滿 100 個讚：0 💎。100 個讚以上：1 個讚 = 1 💎，每支影片最高 1,000 💎。
  • 發布於 TikTok、YouTube 或 Reels。同一支影片發布在多個平台，可分別領取獎勵。
  • 每支影片限提交 1 次；每個 User ID 每月最多 30 支影片。
  • 每個 User ID 累計獎勵上限 20,000 💎。
  • 按讚數以提交表單當下為準，且須在數據截圖中清楚顯示。
參加條件
  • 影片畫面需有 imely 標誌或 App 介面，並加上 hashtag #imely。
  • 影片主要內容須為 imely 的使用體驗；可以出現其他 App，但比重不宜過多。
禁止灌讚／灌觀看數

imely 保有最終審核權。若發現灌讚／灌觀看數，該 User ID 將被取消活動資格。

影片內容規範

影片須為 SFW：適合所有觀眾，且不違反平台社群守則。

02

影片須為 SFW

必須做到

  • 影片及所有公開顯示的內容（頭像、名稱、簡介、說明文字、hashtag）都須為 SFW。
  • 18+ 角色可以像電影預告一樣介紹，但不得呈現 NSFW 細節。
  • 觀看、按讚、留言數必須真實；imely 會在提交時審查數據。

不得出現

  • 髒話或粗口；暴力、色情、恐怖的畫面或聲音。
  • 歧視或仇恨言論。
  • 宣傳危險行為、自我傷害或自殺。
  • 將角色／使用者設定為未成年人並置於戀愛或性暗示情境。
  • 關於 imely、個人、組織的不實資訊，或扭曲歷史。
  • 使用可辨識的真人影像作為素材。
  • 使用機器人或付費服務購買的觀看數、按讚數或追蹤者。
