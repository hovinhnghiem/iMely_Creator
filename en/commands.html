Command library for characters

Commands give your character its own interface: a phone, a diary, a quest panel, a forum. The user types a command and the AI replies in the layout you chose. Pick the commands that fit your character, copy them and paste them into your character in the imely app.

How to write a command

            
Every command has 4 parts. Use this to edit the samples or write your own for your story world: cultivation, sci-fi, school, idol…

          

          03
        

        

          
/command:Required
The name the user types to trigger it. No spaces or accents, write it as one word or use _, short and easy to remember.
Good: diary forum messages. Avoid: Quest System cmd1

          
desc:Required
1–2 sentences that answer 3 things: what the command produces, what tone it uses, and what it does for the story (reveal secrets, create drama, track progress…).

          
rules:Optional
Only needed when the command must follow strict logic: quests, stats, affection. Each line starts with * and reads like “Always…”, “Never…”, “Only … when …”, with value limits such as 0–100.

          
format:Required
The display layout, the most important part. The more specific it is, the more consistently the AI keeps it.

        


        

          
Write a format the AI can keep

          
    
            
  • Title line: emoji + CAPITALIZED NAME, e.g. 📋 FORUM · [board name].
    • 
            
  • Divider: copy this exact character line ───────────────.
    • 
            
  • Use [square brackets] for parts the AI fills in, and {{user}}, {{char}} so names are filled in automatically.
    • 
            
  • State amounts and lengths: “3–5 posts”, “1–2 sentences”, “80–120 words”.
    • 
            
  • Optional closing line for the character's action or feeling, wrapped in ＊…＊.
    • 
            
  • If the format has several blocks (post + comments), separate each block clearly.
    •

Before you publish

          

            
Use 3–5 commands per character
Too many commands confuse the AI and it forgets the layouts. Keep the ones that really serve the story.

            
Match the command's tone to the character
A Gen Z character gets Gen Z commands, a historical character gets old-fashioned wording. Adjust app names, currency and forms of address in the samples to fit your world.

            
Test for 5–10 turns
Try each command over 5–10 chat turns and check that the AI keeps the layout, amounts and stats before you publish.

            
Content still follows the criteria
What commands generate must still meet the review criteria, including keeping public content SFW.
