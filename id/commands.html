Beranda/Panduan Creator/Koleksi command

Koleksi command untuk karakter

Command memberi karakter tampilan sendiri: ponsel, diary, panel misi, forum. User mengetik command, AI membalas sesuai format yang kamu pilih. Pilih command yang cocok, salin, lalu tempel ke karakter di aplikasi imely.

Pilih command → Cara menulis command
/phone 
📱 PONSEL ARKA
───────────────
🔋 12% · 01.47
🔔 Notifikasi
• Kalender: Ulang tahun dia, 3 hari lagi
• Pesan: Ibu: "Akhir pekan pulang makan ya"
🔍 Pencarian terakhir
• kado untuk orang yang tidak suka manis
• cara minta maaf tanpa bilang maaf
───────────────
＊Dia buru-buru menelungkupkan ponselnya di meja.＊
Koleksi Set kamu Cara menulis

Pilih command

36 command siap pakai dalam 4 grup. Cari atau filter sesuai vibe karaktermu, ketuk “Tambah ke set” untuk mengumpulkan beberapa, lalu sesuaikan dengan dunia ceritamu.

Ponsel

/phone

Notifikasi, riwayat pencarian, dan hal yang disembunyikan char.

RahasiaDrama
Lihat command 
/command: phone
desc: Layar ponsel {{char}} saat ini: notifikasi baru dan riwayat pencarian. Gaya santai sehari-hari, pakai emoji. Mengungkap hal yang sedang dipikirkan atau disembunyikan {{char}}.
rules:
  * Isi sesuai dengan kejadian terbaru dalam cerita
  * Hanya beri petunjuk 1–2 rahasia setiap kali, jangan bongkar semuanya
format:
  📱 PONSEL {{char}}
  ───────────────
  🔋 [baterai]% · [jam]
  🔔 Notifikasi
  • [nama aplikasi]: [isi, 1 kalimat]
  (2–3 notifikasi)
  🔍 Pencarian terakhir
  • [kata kunci]
  (3–4 kata kunci, minimal 1 yang mencurigakan)
  ───────────────
  ＊[reaksi {{char}} saat memergoki {{user}} memegang ponselnya]＊

rules:
  * Lawan bicara harus karakter yang sudah muncul atau pernah disebut

  ───────────────
  [nama lawan bicara] · [jam]
  [pesan]
  {{char}} · [jam]
  [pesan]
  (6–10 pesan, bergantian, boleh spam chat)
  ───────────────
  [Dibaca / Terkirim / Sedang mengetik...]

Lihat command 
/command: status
desc: Panel status {{char}} secara real time. Gaya statistik game, singkat. Mencerminkan situasi agar {{user}} tahu apakah {{char}} baik-baik saja.

  Mental:  [▮▮▮▮▮▯▯▯▯▯] [x]/100

Sebelum publish

          

            
Pakai 3–5 command per karakter
Terlalu banyak command membuat AI bingung dan lupa format. Pilih yang benar-benar mendukung cerita.

            
Gaya command sesuai karakter
Karakter Gen Z pakai command bergaya Gen Z, karakter kerajaan pakai bahasa klasik. Sesuaikan nama aplikasi, mata uang, dan sapaan di contoh dengan duniamu.

            
Uji 5–10 giliran
Coba setiap command selama 5–10 giliran chat, pastikan AI menjaga format, jumlah, dan statistik sebelum publish.

            
Konten tetap mengikuti kriteria
Hasil dari command tetap harus memenuhi kriteria review, termasuk konten publik yang SFW.
